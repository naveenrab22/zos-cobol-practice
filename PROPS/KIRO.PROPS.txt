* ACS POLICY RULES FOR THIS SYSTEM (Z50996 - ZXPC)                  *
*=====================================================================*
* 1. SPACE UNIT    : MUST USE TRK OR K - CYL IS REJECTED BY ACS     *
* 2. LOAD MODULES  : MUST USE DSNTYPE=LIBRARY (PDSE) NOT PDS         *
*                    ACS REJECTS PDS FOR VERSION 3 LOAD MODULES      *
* 3. ALLOCATION    : SIZE OVER 200KB IS REDUCED BY SMS AUTOMATICALLY *
* 4. RECFM=U       : ONLY VALID FOR LOAD MODULE LIBRARIES            *
* 5. RECFM=FBA     : REQUIRED FOR PRINT/LISTING DATASETS (LRECL=133) *

* COMPILE AND RUN FLOW SUMMARY                                       *

* STEP 2 - COMPILE JCL  : Z50996.AI.PRACTICE.JCL(COMPILE)          *
*           COMPILER     : READS  COBOL(pgmname)  VIA SYSIN          *

*                          WRITES LIST(pgmname)   VIA SYSPRINT       *
*           LINK-EDIT    : READS  OBJ(pgmname)    VIA SYSLIN         *
*                          WRITES LOAD(pgmname)   VIA SYSLMOD        *
* STEP 3 - VERIFY        : CHECK LOAD(pgmname) EXISTS = COMPILE OK   *
* STEP 4 - RUN JCL       : Z50996.AI.PRACTICE.JCL(RUN)              *
*           EXECUTE      : PGM=pgmname                               *
*                          STEPLIB = Z50996.AI.KIRO.LOAD             *
*                          SYSOUT  = SYSOUT=*,OUTLIM=15000           *
*                          CEEDUMP = DUMMY                           *
*                          SYSUDUMP= DUMMY                           *
* STEP 5 - CHECK RC      : RC=0000 SUCCESS                           *
*                          RC=0004 WARNING - REVIEW OUTPUT           *
*                          RC=0008 ERROR   - CHECK SYSOUT            *
